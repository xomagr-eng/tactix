# TACTIX — Προπονητής Ποδοσφαίρου

Offline εφαρμογή (PWA) για τον **προπονητή ποδοσφαίρου**: τακτικές, σχέδια, προπονήσεις, αγώνες και ανάλυση.

## Χαρακτηριστικά
- 🧠 **Τακτικές μεγάλων προπονητών** (Guardiola, Klopp, Simeone, Mourinho, Arteta, Ancelotti, Bielsa, Mendilíbar, Xabi Alonso, De Zerbi, Conte κ.ά.) + δικές σου, με διαδραστικό ταμπλό, ρόλους ανά θέση (FM-style), κινήσεις και παρουσίαση.
- 📐 **Σχέδια / Playbook**: στημένες φάσεις και patterns.
- 🏃 **Προπονήσεις**: βιβλιοθήκη ασκήσεων, προπονητικές μονάδες, μικρόκυκλος (Tactical Periodization).
- 👥 **Ρόστερ** με χαρακτηριστικά 1–20, καταλληλότητα θέσεων, φυσική κατάσταση & ηθικό.
- ⚽ **Αγώνες**: σύνθεση, ανάλυση αντιπάλου, αποτελέσματα, στατιστικά.
- 🔗 **Σύνδεση με το [DATA COACH 360°](https://xomagr-eng.github.io/datacoach-360/)**: ρόστερ από πραγματικά δεδομένα, προτεινόμενη 11άδα, report αντιπάλου και ασκήσεις εβδομάδας — απευθείας, χωρίς αρχεία.
- 📱 Κινητό, τάμπλετ, υπολογιστής — εγκατάσταση στην αρχική οθόνη, λειτουργία **offline**.
- ⬇ Εξαγωγή σε Word / Excel / PDF / εικόνα.

## Χρήση
Άνοιξε τη live έκδοση (GitHub Pages) ή το `index.html` σε οποιονδήποτε browser. Τα δεδομένα μένουν τοπικά στη συσκευή σου.
